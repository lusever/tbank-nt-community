# T-Bank Invest API contracts redistribution permission

This file records the written permission relied upon when redistributing protobuf contracts from
the public T-Bank Invest API repositories and Rust bindings generated from those contracts.

- Source organization: T-Bank Invest Open Source SDK
- Public repository group: https://opensource.tbank.ru/invest
- Confirmation received: 2026-08-07

The project author asked T-Bank:

> Правильно ли я понимаю, что `.proto`-контракты из `invest-contracts`, а также сгенерированный на
> их основе код можно включать в независимые open-source проекты и распространять, в том числе
> через crates.io, на условиях Apache License 2.0 с сохранением необходимых уведомлений?

T-Bank replied:

> Да, все верно. Все что размещено в публичных репозиториях свободно для распространения.
> https://opensource.tbank.ru/invest

The Apache License 2.0 text is provided in `LICENSES/Apache-2.0.txt`. Exact provenance for the
vendored contract snapshot is recorded separately in `proto/contracts.lock`.
