# Security policy

## Reporting a vulnerability

Please report vulnerabilities through GitHub's private security advisory flow for this repository.
Do not open a public issue containing credentials, account identifiers, broker request IDs, venue
order IDs, tracking metadata, or reproduction artifacts with live account data.

Include the affected version, impact, and the smallest redacted reproduction you can provide. Do
not submit real orders or probe accounts you do not own while investigating.

## Supported versions

Until the first stable release, security fixes are made on the latest tagged `0.1.x` release and
the `main` branch only.
